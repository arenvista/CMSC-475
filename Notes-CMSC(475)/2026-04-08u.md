# Transformers: From Self-Attention to Multi-Head Attention

To understand Multi-Head Attention, we first need to establish how basic Self-Attention transforms isolated words into context-aware representations.

## 1. The Core Self-Attention Mechanism

When words are first fed into a Transformer, they are represented as **Non-Context-Dependent Embeddings** (raw vectors). The goal of the Attention mechanism is to update these into **Context-Dependent Embeddings** ($Z$), where each word's vector is infused with the meaning of the surrounding words.

We achieve this by projecting the input sequence $X$ into three distinct matrices: **Queries ($Q$)**, **Keys ($K$)**, and **Values ($V$)**.

### The Attention Matrix ($P$)
First, we compute the attention weights, which represent how much focus each word should give to every other word. We take the dot product of the Queries and Keys, scale it by the square root of the key dimension ($\sqrt{d_k}$) to stabilize gradients, and apply a Softmax function:

$$P := \text{Softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)$$

### The Contextual Output ($Z$)
Next, we multiply this probability matrix $P$ by our Values ($V$). This operation computes a weighted sum of the values, resulting in our final context-aware embeddings:

$$Z := P V = \text{Softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$

---

## 2. The Limitation of Single-Head Attention

If a Transformer only uses a single attention mechanism (one "head"), it faces two major limitations:

1.  **The "Self-Obsession" Problem (Diagonal $P$):** A single attention head will often learn to place the highest probability weight on the word itself. If the attention matrix $P$ becomes heavily diagonal, the model effectively ignores the surrounding context and just returns the original word embedding.
2.  **Single Representation Space:** Language is complex. In a given sentence, a word might need to simultaneously attend to its adjective, its verb, and its grammatical object. A single attention head struggles to capture all these different *types* of relationships at once because it is constrained to a single representation subspace.

---

## 3. Multi-Head Attention

**The Solution:** Instead of performing a single attention function, we run $n$ (or typically $h$) attention functions in parallel. Each "head" has its own set of independently learned weight matrices for $Q, K,$ and $V$. 

This allows the model to simultaneously attend to information from different representation subspaces at different positions. For example, Head 1 might focus on subject-verb relationships, while Head 2 focuses on positional proximity.

### The Mathematical Pipeline for $n$ Heads

For $n$ heads, we compute the attention for each head independently:

$$
\begin{gathered}
Z_1 := \text{Softmax}\left(\frac{Q_1 K_1^\top}{\sqrt{d_k}}\right)V_1 \\
Z_2 := \text{Softmax}\left(\frac{Q_2 K_2^\top}{\sqrt{d_k}}\right)V_2 \\
\vdots \\
Z_n := \text{Softmax}\left(\frac{Q_n K_n^\top}{\sqrt{d_k}}\right)V_n
\end{gathered}
$$

### Concatenation and Final Projection

Once all heads have computed their context-aware outputs, we concatenate them horizontally into a single massive matrix. Because we want our final output to seamlessly feed into the next layer of the neural network, we multiply this concatenated matrix by a final learned linear projection matrix, $W_o$:

$$Z_{\text{Final}} := [Z_1; Z_2; \dots; Z_n] W_o$$

*(Note: $W_o$ mixes the insights gathered from all the independent attention heads back together into a unified representation).*

---

## 4. Dimensionality and Efficiency

You might assume that using 8 attention heads is 8 times more computationally expensive than using 1. However, Transformers split the embedding dimensions across the heads to keep the computational cost constant.

Let $d_{\text{model}}$ be the total dimension of the word embeddings (e.g., 512). 
Let $n$ be the number of attention heads (e.g., 8).

We define the dimensionality of the Keys, Queries, and Values ($d_k$ and $d_v$) for *each individual head* as:

$$d_k = d_v = \frac{d_{\text{model}}}{n}$$

For example, if $d_{\text{model}} = 512$ and $n = 8$, then each head operates in a 64-dimensional space ($512 / 8 = 64$). 

Because the dimensions are reduced for each head, the total computational cost of Multi-Head Attention is roughly the same as single-head attention with full dimensionality. When the outputs $Z_1 \dots Z_n$ (each of size 64) are concatenated, they perfectly reconstruct the original model dimension of 512.
